# Gestión de Usuarios - CRUD en PHP y MySQL

## Descripción breve
Aplicación web desarrollada para la gestión básica de usuarios mediante operaciones **CRUD** (Crear, Leer, Actualizar y Eliminar). Permite registrar nuevos usuarios con su nombre, apellidos, nombre de usuario y contraseña, visualizar el listado completo en una tabla dinámica, editar registros existentes y eliminarlos de la base de datos de forma inmediata.

## Tecnologías utilizadas
* **Backend:** PHP (extensión `mysqli` para conexión y consultas a base de datos)
* **Base de datos:** MySQL / MariaDB
* **Frontend:** HTML5 y CSS3
* **Entorno de servidor local:** Apache (XAMPP / Laragon / WAMP)
